# Agent Note: ask_user_question forwards question detail

Status: implemented

English | [中文](2026-08-16-tool-ask-user-question-detail.zh.md)

## Problem

`AskUserQuestionItem` declares an optional `detail` field, the wire schema validates it, and the web question UI renders it as markdown below the question title. The `ask_user_question` tool schema did not declare `detail`, and its execute mapping dropped the field, so the model could not express detail through the tool at all.

## Decision

The `ask_user_question` tool schema declares `detail` as an optional string and the execute mapping forwards it to `ctx.userQuestions.ask()`. The field description reuses the contract's wording: supporting detail rendered with the question but kept out of option labels. The web UI's existing markdown rendering of `detail` is unchanged. `docs/tool-catalog.md` is regenerated by `doc-sync`.

## Alternatives considered

**Encode longer questions in the `question` text** — rejected. The web UI renders `question` as a plain-text heading, so markdown there does not render.

**Declare `detail` without forwarding it** — rejected. A schema-only field would never reach the UI.
